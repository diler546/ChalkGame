# МЕЛОК: Ночной Вернисаж

**Бесплатная браузерная игра в стиле платформера с пазлами и управлением мелом.**

## 📖 Описание

**МЕЛОК: Ночной Вернисаж** — это HTML5 Canvas игра, где вы играете роль художника, который должен восстановить утраченное сияние восьми картин ночной галереи. Игра сочетает в себе физику платформеров, пазлы и управление ограниченными ресурсами.

### Сюжет

Ночь. Галерея закрыта, но картины не спят. Сторож ушёл, оставив дверь на замке. Восемь залов. Восемь полотен. Три печати. У вас только мел и краска. Мосты тают. Ваша задача — вернуть свет на стены до рассвета.

## 🎮 Как играть

### Управление

**Клавиатура:**

- `← →` или `A D` — движение влево/вправо
- `Space` / `W` / `↑` — прыжок
- `P` / `Esc` — пауза
- `Z` — продолжить (в меню)

**Экранные кнопки:**

- Кнопки сложности (Лёгкий / Средний / Сложный)
- Звук: Вкл/Выкл
- Действия: Начать, Продолжить, Заново, В меню

### Цель игры

Пройти восемь залов ночной галереи, избегая пропастей и врагов, используя меловыеbrücken для пересечения пропастей. Собрав достаточно краски и решая пазлы, вы откроете путь к выходу.

## 🎨 Механики игры

### Система краски

- Краска ограничена в зависимости от выбранной сложности
- Регенерация происходит со скоростью, зависящей от сложности
- Каждый мост через пропасть (по 230 px) стоит около 61 единицы краски
- Краска не тает и сбрасывается только при полном рестарте забега

### Уровни сложности

| Сложность   | Краска | Реген/сек | Жизни | Бонус |
| ----------- | ------ | --------- | ----- | ----- |
| **Лёгкий**  | 90     | 2.5       | 5     | 5     |
| **Средний** | 50     | 1.1       | 3     | 10    |
| **Сложный** | 26     | 0.45      | 1     | 15    |

### Платформы и препятствия

- **Полы** — полная поверхность для стояния
- **Полки (ledge)** — мелкие платформы
- **Мосты (bridge)** — длинные платформы с опорными кронштейнами
- **Карнизы (cornice)** — декоративные балки
- **Пропасти** — по 230 px каждый, требуют построения моста мелом

### Враги

1. **Patrol** — ходит по площадке и разворачивается у края
2. **Jumper** — прыгает на месте
3. **Flyer** — летает по синусоиде
4. **Shooter** — стоит на точке и стреляет снарядами

Снаряды shooter'ов можно перекрыть нарисованными мелом стенами.

### Пазлы (три печати)

В игре три пазла с разными контурами:

1. **Квадрат** — 6×6 клеток
2. **Круг** — радиус 4 клетки
3. **Ромб** — радиус 4.6 клетки

Необходимо закрасить 80%+ клеток внутри контура, чтобы снять печать. Ячейки внутри пазла не тратят краску и не входят в лимит 220 мазков.

## 🏆 Статистика

После победы или поражения отображается статистика:

- **Счёт** — набранные очки
- **Рекорд** — лучший счёт (сохраняется в localStorage)
- **Картины** — сколько из 8 картин восстановлено
- **Пазлы** — сколько из 3 печатей решено
- **Время** — длительность забега
- **Сложность** — выбранный уровень
- **Краска** — оставшееся количество
- **Падения** — число падений в пропасти

## 🔊 Звук

Все звуки генерируются синтетически (осцилляторы), файлов звука нет. Можно отключить звук через кнопку или клавишу `Z`.

## 💾 Сохранение

- Уровень сложности сохраняется в localStorage
- Настройка звука (вкл/выкл) сохраняется в localStorage
- Рекорд сохраняется в localStorage

## 🎛️ Настройки в игре

- Переключение сложности перед каждым забегом
- Включение/выключение звука
- Пропуск кат-сцен (пропуск проигрыва)
- Рестарт уровня

## 🛠 Технические детали

### Технологии

- HTML5 Canvas для рендеринга
- ES6 Modules для структуры кода
- Web Audio API для синтетического звука
- localStorage для сохранений

### Структура файлов

- `index.html` — основная структура игры
- `main.js` — точка входа, управление UI
- `Game.js` — основная логика игры, сложности, кат-сцены
- `Player.js` — управление игроком, физика
- `EnemyManager.js` — управление врагами и снарядами
- `Level.js` — данные уровней, платформы, пропасти
- `Puzzles.js` — системы пазлов и печатей
- `Enemies.js` — конфигурации врагов
- `Collision.js` — геометрические хелперы и работа с сеткой 12×12
- `Camera.js` — плавная камера с follow-эффектом
- `Audio.js` — синтетический аудио-движок
- `Input.js` — обработка ввода с клавиатуры, мыши и сенсорных экранов
- `Brush.js` — рисование мелом
- `Style.css` — стили оформления

### Баланс

- **Хардкорный баланс**: краска scarce (мало), регенерация медленная
- 8 мостов по 230 px каждый — всего около 61 краски на каждый мост в hard режиме
- Каждый забег требует планирования расходов краски

## 📱 Поддержка

Игра работает в современных браузерах с поддержкой HTML5 Canvas и Web Audio API. Рекомендуется использовать десктопный браузер или мобильное устройство с поддержкой тач-контрола.
